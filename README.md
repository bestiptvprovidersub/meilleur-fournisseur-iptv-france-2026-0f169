## 🛠️ Optimisation Matérielle & Configuration Réseau



### Recommandations pour un Flux 4K Stable :
- **Connexion Réseau** : Câble Ethernet RJ45 (Cat 6 minimum) préconisé pour éliminer la gigue Wi-Fi.
- **Applications Conseillées** : TiviMate IPTV Player, IPTV Smarters Pro, ou Formuler MyTVOnline 3.
- **Gestion du Tampon (Buffer)** : Configurer le buffer entre 3 et 5 secondes pour les retransmissions sportives en direct.
- **DNS Personnalisés** : Cloudflare DNS (1.1.1.1) ou DNS.SB pour un temps de résolution CDN minimal depuis les FAI francophones.
